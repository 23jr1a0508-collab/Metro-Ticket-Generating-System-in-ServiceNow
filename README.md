Project Overview:
The Metro Ticket Booking System is a ServiceNow-based digital solution designed to simplify and automate the metro ticket
booking process. Users can submit a booking request by selecting the source station, destination station, travel date, and
passenger details. The system processes the request through Service Catalog and Flow Designer, calculates the applicable
fare, generates a digital ticket with a QR code, and sends a confirmation notification. The solution aims to reduce manual
effort, minimize waiting time, improve accessibility, and provide a convenient digital travel experience.
Problem Statement
Conventional metro ticket booking may require users to wait in queues, interact with manual ticketing processes, and spend
additional time obtaining tickets during busy periods. The absence of a streamlined digital workflow can increase processing
time and operational effort. This project addresses the problem by implementing an automated ServiceNow workflow that
enables digital booking, automated fare calculation, QR-code ticket generation, and notification delivery. The proposed
system provides a faster and more accessible alternative to manual ticket booking while improving process consistency and
user convenience.
Project Objectives
• Digitize the metro ticket booking process using ServiceNow.
• Allow users to select stations and provide required travel details through a Service Catalog item.
• Automate fare calculation based on the selected journey details.
• Generate a unique digital ticket containing a QR code after successful booking.
• Use Flow Designer to automate validation, processing, ticket generation, and status updates.
• Send automated notifications to confirm bookings and provide ticket information.
Project Success Criteria
The project will be considered successful when a user can submit a metro ticket booking request through ServiceNow, provide
valid journey details, receive an automatically calculated fare, and obtain a generated digital ticket containing a QR code. The
workflow should process requests consistently through Flow Designer, update booking status, and send appropriate
notifications. The final implementation should demonstrate a complete and efficient digital ticket booking journey.
